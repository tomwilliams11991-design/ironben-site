הצעות

מוצרים ותמחור

ק"ג ושעות הם הבסיס לכל מחיר. עד שמסמנים "אומת" ההצעות מציגות אזהרה. "מחיר שרת" הוא מה שהאתר מחשב ללקוח (עם ברירות המחדל של הקונפיגורטור), לבדיקה שהשרת והניהול מסכימים.

סכמת קלט לקונפיגורטור

לכל מוצר: אילו מידות הלקוח מזין (fields), איך מחשבים כמות (formula: count / length / area_wl / area_wh / units), אילו גימורים ועצים (עם מקדם מחיר), ואיזה מודל 3D (model).
